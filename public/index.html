Unconscious
  • Protect airway.
  • Recovery position if breathing.
  • Monitor responsiveness continuously.
Cardiac arrest
  • Call for AED.
  • Start CPR immediately.
  • Keep compressions continuous.
Circulatory collapse
  • Control heat / cold stress.
  • Lay patient flat if appropriate.
  • Prepare rapid evacuation.
Severe bleeding
  • Direct pressure.
  • Tourniquet / packing if needed.
  • Reassess perfusion and loss.
Fractures
  • Immobilise.
  • Check distal circulation.
  • Move only as required for safety.
